1、选择建图范围和建图行走路线。尽量多绕小圈，后面的路线需要前面已记录点进行参考修正，来减少误差。
2、到达建图起点后，分别将线插入电脑、雷达和电源，并开启电源。将雷达放在平面上垂直，朝向前方，最终建图的方向为最开始雷达所处的方向。
3、在电脑上启动建图相关程序。以建图用的电脑为例，通常默认情况下，雷达ip地址和其他建图参数等已经配置好，不需要修改。只需要检查雷达是否连接上，然后点击文件夹，进入home/carto3/的目录中，右键“open in terminal”打开终端，运行命令，等待相关程序窗口打开有响应后，即可开始建图。
4、将雷达拿起来稍微朝前面斜下方倾斜，然后开始按照路线行走。（用于建图的雷达是类似G3的雷达，它的距离是40m左右，而像S1顶上的雷达可达到100m。且G3雷达平着的时候水平斜向下的度数较小，所以在建图时一般需要倾斜20-40°，来确保扫描的效果。除非是很空旷且没有参照的地方可以平着拿着走一会儿）
5、一般走路中间，确保两边路沿可以扫描到。来往有行人或车辆时，速度稍慢一些，让他们先通过后继续走。尽量选择人和车辆少的时间段去建图。建图行走时不要并排着走。尽量选大晴天出去建图，周围不要有水坑，不然会有激光反射的情况，导致点变稀疏。尽量不要走进死胡同再走出来，会导致点云误差越来越偏。有时间可以多走几遍。
6、来回上下坡，建图的高度可能存在误差。走完后回到起点位置闭环，让程序自己去慢慢修正闭合。如果还是不行，就尝试手动去慢慢修正（修改参数）。
7、走完后，ctr c中断程序，然后save保存建图数据。
8、点位修正，点关联，参数优化。数据处理，生成地图，3D转2D。
（通常建完回来后将电脑给明阳，把home/carto3/data/archive/保存的地图数据文件，拷过去。明阳处理完并生成图后，还需要修图和检查，最后上传到后台）【points.ply/map.png/map.yaml】


常用相关命令：
运行建图：docker compose up
保存当前建图会话：docker compose run --rm save 地图名称
查看当前建图会话：docker compose run --rm viewer
查看已保存的建图会话：docker compose run --rm viewer 地图名称
重放当前建图会话：docker compose run --rm replay
重放已保存的建图会话：docker compose run --rm replay 地图名称
删除当前建图会话：docker compose run --rm clean
删除已保存的建图会话：docker compose run --rm clean 地图名称


注意事项：
---建图的路线规划主要就是注意先闭小环，再闭大环。
    以重电南区举个例子，这种大的地图建图的时候应该先一个区域一个区域的闭环，而不是先走外面的路，再覆盖里面的区域。
    当然小点的区域也可以先走外面再覆盖里面，可以多建几次摸索一下。
---有时候因为环境限制只能闭大环，如果发现地图没有闭环也不要慌张，接着走就行了，后期可以手动闭环。
---最重要的是保证里程计是正确的，不要出现那种人在往前走，但是程序显示的地图数据却没有跟着走的情况。出现这种情况后期调参数回放也可能处理不了，最好现场解决。
    根据现场情况调整里程计的参数，看是否能解决；或者调整激光雷达的角度，让它能看到有特征的地方；实在不行就把这个位置放到最后，或者避开这个位置。
---在建图过程中，如果电脑快没电了、或雷达电源线掉了、显存满了等异常情况，导致只建了一部分，应该保存上次会话，在停的地方接着开新的，后面回去合并。
---如果存在上下两层的情况，需要分开建，不然会有重叠。例如上面是广场公路，下面是车库这种。
---如果存在上下两层的情况，但需要的区域没有重叠，则可以一起建。例如上层左侧是广场公路，下层右侧是车库这种。
