1、选择建图范围和建图行走路线。尽量多绕小圈，后面的路线需要前面已记录点进行参考修正，来减少误差。
2、到达建图起点后，分别将线插入电脑、雷达和电源，并开启电源。将雷达放在平面上垂直，朝向前方，最终建图的方向为最开始雷达所处的方向。
3、在电脑上启动建图相关程序。
4、将雷达拿起来稍微朝前面斜下方倾斜，然后开始按照路线行走。
5、一般走路中间，确保两边路沿可以扫描到。来往有行人或车辆时，速度稍慢一些，让他们先通过后继续走。尽量选择人和车辆少的时间段去建图。建图行走时不要并排着走。尽量选大晴天出去建图，周围不要有水坑，不然会有激光反射的情况，导致点变稀疏。尽量不要走进死胡同再走出来，会导致点云误差越来越偏。有时间可以多走几遍。
6、来回上下坡，建图的高度可能存在误差。走完后回到起点位置，让程序自己去慢慢修正闭合。如果还是不行，就尝试手动去慢慢修正。
7、后续就是回放修正点位，点关联，参数优化。地图3D转2D。


相关命令：
运行建图：docker compose up
保存当前建图会话：docker compose run --rm save 地图名称
查看当前建图会话：docker compose run --rm viewer
查看已保存的建图会话：docker compose run --rm viewer 地图名称
重放当前建图会话：docker compose run --rm replay
重放已保存的建图会话：docker compose run --rm replay 地图名称

建图的路线规划主要就是注意先闭小环，再闭大环。
以重电南区举个例子，这种大的地图建图的时候应该按绿色的线走一个区域一个区域的闭环，而不是按红线先走外面的路，再覆盖里面的区域。
当然小点的区域也可以先走外面再覆盖里面，可以多建几次摸索一下。
有时候因为环境限制只能闭大环，如果发现地图没有闭环也不要慌张，接着走就行了，后期可以手动闭环。
最重要的是保证里程计是正确的，不要出现我刚刚说的那种人在往前走，但是程序显示的地图数据却没有跟着走的情况。出现这种情况后期调参数回放也可能处理不了，最好现场解决。
根据现场情况调整里程计的参数，看是否能解决；或者调整激光雷达的角度，让它能看到有特征的地方；实在不行就把这个位置放到最后，或者避开这个位置。
